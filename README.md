DP Analysis Project

A project focused on analyzing the Gross Domestic Product (GDP) of countries from 2005 to 2022 using Python, Pandas, Power BI.

Project Structure
gdp-analysis/
├── data/              # Cleaned CSV data
├── notebooks/         # Jupyter notebooks
├── power_bi/          # Power BI dashboard file (.pbix)
├── scripts/           # Python scripts
├── screenshots/       # Dashboard screenshots (optional)
├── README.md

Features:
Removed commas, whitespaces, and null(NaN) values.
Converted text to numerical data types.
Exported cleaned dataset to clean_gdp.csv.

Analysis with Pandas:
Identified the best GDP year per country.
Identified the worst GDP year per country.

Visualization with Power BI:
Line chart: GDP trends over time with country filter.
Pie chart: Distribution of best GDP years.
Interactive slicers for country and year.

Tech Stack:
Python (pandas, matplotlib).
Power BI.
